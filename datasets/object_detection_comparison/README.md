# Imágenes para la comparación de detectores

Tres imágenes sintéticas.

| Archivo | Propósito |
|---|---|
| `01_escena_cotidiana.png` | Persona, perro y automóvil grandes y reconocibles. |
| `02_oclusiones.png` | Objetos parcialmente ocultos y personas pequeñas en una cafetería. |

Estas imágenes son ejemplos de inferencia, no datos de entrenamiento ni un conjunto de evaluación anotado. Su adecuación visual fue revisada; las respuestas de los detectores todavía no se han comprobado. No se garantizan detecciones ni diferencias concretas entre modelos.
